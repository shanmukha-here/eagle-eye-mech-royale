# Running the local placement board

From a full checkout, run `./localboard.sh`. Set `MECHFIGHT_KIT` to the unpacked official kit if it is outside the default sibling path `../brief/kit/mechfight-kit`. The runner needs Linux, Python 3.9 or later, a C compiler, and Git history containing both reference revisions. It builds a small shared library in the result cache. The submitted bot has no evaluator dependencies.

The default command scores the working bot and both reference commits on 96 development and 200 held-out starts each. It prints mean placement points, a two-sided 95% interval and the paired change against phase 2. Each match earns 16 minus the bot's place. The raw seed-level results are cached outside the repository. Use `--cache PATH` for a clean run. The private calibration ledger at `../CALIBRATION.md` supplies the median board/local ratio. To use an external ledger, pass `--calibration PATH`. To use a known multiplier, pass `--ratio NUMBER`.

The runner uses Docker if installed. Pass `--docker` for release checks. Each subject runs from its pinned Dockerfile on one assigned CPU with 512 MiB, no swap or network, UID 65534, no capabilities, a read-only filesystem, a 64 MiB temporary filesystem and a 128-process limit. On a machine without Docker, `--native` pins each match and subject to one CPU and applies a 512 MiB process address-space limit. Both modes run the kit's checker before matches. A failed check rejects the run. A late match decision coasts, then idles, and a crashed bot keeps its eventual place. Deadlines use wall time, so isolated seeds can differ under host contention. Docker and native results use separate caches.

Use `./localboard.sh --split dev --workers 48 --native` while developing. The `cal` split is for fitting the squad mix. Freeze the policy before running the holdout. Use `--ffa` to turn off squad coordination for a separate finals-style comparison. Practice calibration applies to the squad pool.

Game constants come from the kit. The 16 mechs play on the real terrain and building footprints at 20 physics ticks and 10 observations per second. The measured subject runs as a real protocol subprocess. Local opponents run in the engine and include the kit starter, two historical policies, a hunter, a camper, a looter and a zone-edge policy. The squad shares sightings and activates its weakest available members first. The activation thresholds, other bots' tactics, random layouts, collision raster and some weapon and NPC interactions approximate the private server. Sampling intervals describe this simulator.

Run `python3 -B check_localboard.py` for rule, schema and failure regressions. Pass `--replay PATH` with the public mechanics-v2 exhibition to check the zone schedule against its saved frames and measure ground-height error at its spawn locations. Neither the map nor replay is included in this checkout.

For a prospective second experiment, `--split devcheck` runs 256 separate development seeds. Use `--test-split confirm` with the default command to select a fresh block of 400 held-out matches per policy. It also reports a two-sided 97.5% interval for the paired gain on that block. Keep the chosen policy and decision rule fixed before reading those outcomes.
